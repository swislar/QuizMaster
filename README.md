# QuizMaster

Sends trivia facts to your Telegram chat, modeled on Quizmaster SG round categories (Firsts, Music, Pictures, Singapore knowledge, Quotes, Celebrities, etc).

## Message format

```
📚 CATEGORY: Firsts

Singapore's first MRT line, the North South Line, began passenger
service on 7 November 1987, running between Yio Chu Kang and Toa Payoh.

🔗 Source: https://www.lta.gov.sg/... 
```
